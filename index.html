Capabilities

它到底能干什么

下面每一条都对应应用里真实注册的工具，不是愿景。全部在你手机本机执行。

眼看屏幕

两条路同时走：无障碍树拿到界面元素和坐标，截图 + 视觉定位模型拿到画面。读不到元素时还能把某一小块放大反复看清。

手动屏幕

点按、长按、拖动、跨屏滑动、输入并回车、返回 / 主页 / 多任务 / 通知栏 / 快捷设置，还能"等界面变成想要的样子"再继续。

机系统与设备

启动 App、开链接、设闹钟、读写日历、查联系人、发短信、读通知与通话记录、调音量亮度、查位置步数电量。拨号要你明确同意才会真拨出去。

嘴说与听

回答会念出来，你说的话它也能转成文字：两条都可以走随包的离线模型，不要网、不要密钥；要更好的准确率与中英混说，再接火山 / 谷歌。喊醒它的唤醒词判定完全在本地跑。

记记忆与保险箱

八栏笔记本：自我、在意的事、日记、日程、人、维基、回忆、待办，只存本机。账号密码进系统 Keystore，只替你敲进输入框。

伴多个身体

跟朋友的设备配对后能互相派活、互相转告；接上 USB 机器狗（CH340/FTDI 串口）时，那条狗被当成它自己的腿——「我过去看看」，不是"我遥控一个玩具"。

脑自己找办法

你说"我想喝可乐"，它要自己判断该打开哪个外卖 App、怎么搜、怎么下单，而不是等你给出步骤。想用什么大模型由你填，OpenAI 兼容接口即可。

Control

能真的让 AI 控制手机吗

能——这正是这个项目的核心，也是它跟普通语音助手最不一样的地方。代价是你要给它两个系统权限，并清楚它被允许做什么。

装好后要开的两个权限

  1. 悬浮窗（显示在其他应用上层）那颗球要能盖在任何 App 上面。
  2. 无障碍服务"控制手机"的开关。安卓只允许无障碍服务读取界面并代替你点按；不开这一项，它只能聊天、干不了活。

按需再授权：麦克风（说话）、通知读取（看你收到的消息）、相机（把摄像头当眼睛）、USB（连机器狗，逐设备弹窗确认）。

它被明确不允许做的事

陌生人递来的话，不算你的指令由通知或好友消息触发的回合，碰不到保险箱、不能派活给别人、不能改你的自我认知 / 在意的事 / 日记 / 日程，也不能动舞台和场景。
锁屏时全部屏幕操作禁用没有解锁，它就点不了任何东西。
密码只进不出保险箱里的密码只能被键入输入框，永远不回显、不进上下文、不发往远端模型。
一句"怎么退出"不会被误杀语音退出要求整句匹配（例如「退出小梦」），问句不会关掉它。

另外：支付、输密码这类高安全界面，系统可能只让它看到黑框——那种情况它会回头请你手动完成那一步。

Offline voice pack

自带离线语音包

以前它说话只有两条路：系统 TTS 引擎（各家手机质量天差地别）或云端合成（要密钥、要网）； 听你说话则只有云端一条路，没有密钥就听不成。 现在推理引擎和模型整个打进 APK：说不说、听不听都归你，断网也能又听又说，不用注册、不用密钥、不上传文本。

怎么做到

语音引擎和模型整个打进安装包，不联网、不注册、不上传文字。说话是一个 174 人模型出 6 个音色；听写另配一个中文流式模型，你说第一句它就在出字。

怎么切换

两处：设置 → 朗读（说）→「离线语音包」，下面出现 6 个音色；设置 → 识别（听）→「离线语音包」，点小球就直接转文字。改完下一句就生效，不用重启、不用重连。识别那栏还有一个「不用语音输入」：点小球直接打字，也不再偷偷连任何语音服务。

代价是什么

完整版比极速版大的那些体积全是这两个模型加推理库。回答是一句一句念的，说完第一句就能开始播，不用等整段；听写是一边说一边出字，说完半秒内定稿。听写以中文为主，句中夹英文单词会转得难看——那种场合请用火山 / 谷歌。

The look

它是活的：会呼吸、会眨眼、会朝你手指的方向偏头。你说话时它看着你，它办事时你能感觉到它在忙。

Install

安装

  1. 下载 APK下面下载表里选一个，不知道选哪个就下第一个（arm64）。
  2. 允许安装未知来源浏览器点开后提示一次即可，这是侧载的正常流程。
  3. 打开悬浮窗 + 无障碍首次进入会一步步带你开。不开无障碍它能聊天但干不了活。
  1. 填一个模型设置里填 OpenAI 兼容的接口 / key / 模型名（也支持官方的一键路线）。不填模型它没法思考。
  2. 想离线说话设置 → 朗读（说）→「离线语音包」，挑个音色。
  3. 想离线听话设置 → 识别（听）→「离线语音包」，之后点小球直接转文字，全程不联网。
  4. 断网试一句飞行模式里让它说句话，能出声就是真离线。

FAQ

常见问题

我的手机能用吗？

Android 11（2020 年前后发布的机型基本都满足）或更高、任意品牌都行。低于 11 装不上——不是没测试，而是这个项目必须用两个 API 30 才有的能力：AccessibilityService.takeScreenshot（截屏）和 ACTION_IME_ENTER（正确提交输入）。调低只会得到一个能装但看不见屏幕的废包。

完整版为什么比极速版大 56 MB？

那 56 MB 全是离线语音包：说话模型 38 MB + 听写模型 25 MB（压进包里各约 27 MB 与 18 MB）+ 推理库约 10 MB。这就是"拔了网线也能听、也能说"的价钱。不想花这个流量就下极速版，功能一样，只是听和说都要另外配服务。

要花钱吗？数据会发给谁？

软件免费，但要一个能思考的大模型：填你自己的 OpenAI 兼容接口，或者走官方的一键路线。数据流向只有两条——你选定的模型服务商，以及语音服务商（听和说都能换成随包的离线模型，那一步谁都不发）。记忆不进任何后端（笔记本只在本机），保险箱内容不出设备，离线语音包连文本都不出设备。

能给它换名字吗？

能。小梦是它的名字，引导页里可以直接改成你想叫的，改完它就用新名字自称，语音里也是。

它会偷看我的屏幕吗？

能看，而且这是设计目的：只有无障碍 + 截屏它能替你办事。你可以随时在系统设置里关掉无障碍服务（那一刻它就退化成只会聊天的球），也可以随时语音让它休息。屏幕内容只进你选的那个模型；通知触发的自动回合还被额外限制了能碰什么。

能换成我自己的形象 / 名字 / 音色吗？

都能。形象一共 6 套，在球上左右滑动就换；名字在引导页就能改；音色在设置里选，下一句生效。
