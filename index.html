小梦
住在手机里的 AI 桌宠

它不是又一个聊天机器人：它看得见你屏幕上的东西，也能替你点下去。 桌面上多一颗会呼吸的小球，点一下跟它说话，长按看它做了什么。 这一版给它加了随 APK 打包的离线语音包——拔了网线它也会开口。

它到底能干什么

下面每一条都对应应用里真实存在的工具，不是愿景。全部在你手机本机执行

眼看屏幕

同时走两条路：无障碍树拿到界面元素和坐标，截图 + 视觉定位模型拿画面。两者互为备份，读不到元素时还能放大某一小块反复看清。

手动屏幕

  • 点按 / 长按 / 拖动 / 滑动（可跨多屏）
  • 输入文字、提交输入框
  • 返回、主页、多任务、通知栏、快捷设置
  • 等界面变成想要的样子再继续

机用系统与设备

  • 启动 App、打开链接、设闹钟
  • 读写日历、查联系人、发短信
  • 调音量亮度、读通知与通话记录
  • 查位置 / 步数 / 电量 / 传感器
  • 拨号需要你明确同意才会真拨出去

嘴说与听

回答会念出来。本版本新增离线语音包（6 个音色，模型随 APK 走，不要网络也不要密钥）；听你说话走云端识别；喊醒它的唤醒词判定完全离线在本地跑。

记记忆与保险箱

八栏笔记本：自我、在意的事、日记、日程、人、维基、回忆、待办，只存本机。账号密码放保险箱（系统 Keystore 加密），它只替你敲进输入框，不回读、不上传。

伴多个身体

跟朋友的设备配对后能互相派活、互相转告；接上 USB 机器狗（CH340/FTDI 串口）时，那条狗被当成它自己的腿——「我过去看看」，而不是"我遥控一个玩具"。

能真的让 AI 控制手机吗？

能——这正是这个项目的设计核心，也是它跟普通语音助手最不一样的地方。代价是你必须给它两个系统权限，并且清楚它被允许做什么、不被允许做什么。

装好后要开的两个权限

  1. 悬浮窗（显示在其他应用上层）那颗球要能盖在任何 App 上面。
  2. 无障碍服务这是"控制手机"的开关。安卓只允许无障碍服务读取界面并代替你点按，不开这一项，它就只能聊天、干不了活。

另外按需授权：麦克风（说话）、通知读取（看你收到的消息）、相机（它把摄像头当眼睛）、USB（连机器狗，逐设备弹窗确认）。

它被明确不允许做的事

陌生人递来的话，不算你的指令。由通知或好友消息触发的回合，碰不到保险箱、不能派活给别人、不能改你的自我认知/在意的事/日记/日程，也不能动舞台和场景。
锁屏时全部屏幕操作禁用。没有解锁，它就点不了任何东西。
密码只进不出。保险箱里的密码只能被键入到输入框，永远不回显、不进上下文、不发往远端模型。
一句"怎么退出"不会被误杀。语音退出要求整句匹配（例如「退出小梦」），问句不会关掉它。

另外：支付、输入密码这类高安全界面，系统可能只让它看到黑框——那种情况它会回头请你手动完成那一步。

自带离线语音包

以前这只桌宠说话只有两条路：系统的 TTS 引擎（各家手机质量天差地别）或云端合成（要密钥、要网）。 这一版把推理引擎和模型整个打进 APK：断网也能说话，不用注册、不用密钥、不上传文本。

怎么做到

sherpa-onnx 推理库（三个 ABI 各一份）+ vits-aishell3 多说话人模型 38 MB，随包解压到应用私有目录。一个模型出 6 个音色，不是 6 个模型。

怎么切换

设置 → 朗读（说）→ 选「离线语音包」，下面出现 6 个音色。改音色下一句就生效，不用重启、不用重连。

代价是什么

APK 大 65 MB；输出采样率 8 kHz（电话音质），首次加载约 1 秒，合成速度约 0.5× 实时——按句切分，第一句很快就响。

以下样本是用 APK 里那份一模一样的模型文件在电脑上直接跑出来的原声，没有经过任何后期。同一句话：「你好，我是住在你屏幕里的桌宠。今天晴，26 度，要不要一起出去走走？」

星辰 默认 · 说话人 140
薄荷 说话人 14

安装

  1. 下载 APK下面的下载表里选一个。不知道选哪个就下第一个（arm64）。
  2. 允许安装未知来源浏览器下载完点开会提示；这是侧载软件的正常流程，只需这一次。
  3. 打开悬浮窗 + 无障碍首次进入会一步步带你开。不开无障碍它能聊天但干不了活。
  4. 填一个模型设置里填 OpenAI 兼容的接口 / key / 模型名即可（也支持官方的 CodeFlying 一键路线）。不填模型它没法思考。
  5. 想离线说话设置 → 朗读（说）→「离线语音包」，挑个音色，断网试一句。

常见问题

我的手机能用吗？

Android 11（2020 年前后发布的机型基本都满足）或更高、任意品牌都可以装。低于 11 的系统装不上——不是没测试，而是这个项目必须用两个 API 30 才有的能力：AccessibilityService.takeScreenshot（截屏）和 ACTION_IME_ENTER（正确提交输入）。把最低版本调低会得到一个能装但看不见于屏幕的废包，所以没有调。

为什么要 85 MB，比原版大这么多？

离线语音包：模型 38 MB + 推理库（每个 ABI 各带一份 onnxruntime 与 sherpa JNI，约 27 MB）。这就是"拔了网线也能说话"的价钱。

要花钱吗？数据会发给谁？

软件本身免费，但要一个能思考的大模型：填你自己的 OpenAI 兼容接口，或者走官方的 CodeFlying 路线。数据流向只有两条——你选定的模型/语音服务商，以及可选的 火山/Google 语音识别。记忆不进任何后端（笔记本是 localOnly），保险箱内容不出设备，本版的离线语音包连文本都不出设备。它是个跑在你手机上的本地 agent，不是云端机器人的客户端。

「小梦」和 Andee 是什么关系？

Andee 是上游开源项目的名字（见 kuafuai/andee ），它的图标和应用名就是它自己，这些我一个字都没改。小梦是这只宠物的名字——应用本来就支持给宠物起名字，我做的事是把默认名设成小梦，并把形象重新画了一遍、加了离线语音包。因为上游许可证不允许对最终用户换掉产品名，所以桌面上那个图标仍然写着 Andee，点进去养的是小梦。

形象到底长什么样？

这一版把默认形象重画成更干净的"豆豆眼"路线：去掉原来的两只角，眼睛收小并靠得更近，双颊加了淡粉腮红，蓝色提亮成天空蓝，只留一个小而对称的笑。页首那张是我照着参数画的示意图——真机上它是 OpenGL 实时渲染的一颗球，会呼吸、会歪头、心情变颜色，以真机为准。

它会偷看我的屏幕吗？

能看，而且这是设计目的：只有无障碍 + 截屏它能替你办事。你可以随时在系统设置里关掉无障碍服务（那一刻它就退化成只会聊天的球），也可以随时语音让它休息。所有屏幕内容只进你选的模型；通知触发的自动回合还被额外限制了能碰什么、不能碰什么。

我能改成自己的形象/名字/音色吗？

都能。形象是一颗程序化绘制的球，全部参数写在一张表里（有六套现成形象可切换）；名字在引导页就能选或自己填；音色对应模型的说话人编号，换一行数字就行。源码和改动清单都在下面。
